# Changelog

## [0.1.0] - 2026-08-02

### Added

- policy-driven TypeScript core with deterministic decision-only mode;
- capability-aware filtering, explainable candidates, cost and latency estimates;
- rules, weighted-score, cheapest-qualified, fastest-qualified, priority, seeded random-weighted, round-robin and cascade strategies;
- retries, fallbacks, health tracking and in-memory circuit breaker;
- OpenAI, Anthropic, Google, OpenRouter and generic OpenAI-compatible adapters;
- CLI, local compatible proxy, offline evaluation, replay, shadow decisions and static playground;
- docs, fixtures, examples, tests, GitHub Actions and Apache License 2.0.
