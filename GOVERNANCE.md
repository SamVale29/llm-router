# Governance

LLM Router is an independent open-source project.

The maintainer owns the release process, security response and compatibility policy. Contributions are reviewed for correctness, privacy, documentation and maintainability. Provider names and APIs are referenced for interoperability; providers do not endorse the project.

Changes to public routing semantics require tests and a changelog note. Catalog updates require source review and are never silently downloaded at runtime. Experimental features must be labeled experimental and opt in.

Decisions are discussed in issues or pull requests. A maintainer may request a design note for changes affecting the core API, policy schema or security posture.
