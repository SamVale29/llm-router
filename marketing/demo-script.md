# Demo script — 60 to 90 seconds

1. Open the static playground.
2. Select Code review and run the decision.
3. Point to the selected model and reason.
4. Open the candidate table and show eliminated capabilities.
5. Select Translation and show the cheapest-qualified strategy.
6. Select Invoice OCR and show image filtering.
7. Select Long summary and show the context requirement.
8. Open Policy editor and change a cost ceiling.
9. Show the fallback chain in the decision trace.
10. Open Architecture and explain constraints before scores.
11. Close with the GitHub repository and invitation for adapter/policy feedback.
